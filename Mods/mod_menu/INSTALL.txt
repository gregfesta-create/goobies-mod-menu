MOD_MENU 1.0.1 DX11 RELEASE CANDIDATE
EXTRACT THIS ZIP DIRECTLY INTO Shooter/Binaries/Win64.
Mods/mod_menu/enabled.txt enables loading without editing Mods/mods.txt.
UE4SS.dll, dwmapi.dll and UE4SS-settings.ini are bundled for this Win64 folder.
Back up an existing loader and its settings before replacing them.
Achievement guard setup below is a separate prerequisite; extracting this ZIP
does not install that guard into the SteamCorePro plugin outside Win64.
Mod Menu only. Menu Options is a separate mod and is NOT included.
Main-menu UI and controls have been tested locally. Final release acceptance
is incomplete: intermittent Escape crash unresolved; real achievement/progress
suppression and cross-computer compatibility remain unverified. Do not treat
this archive as a fully verified final release or use it for valuable progression.

Dependencies, supplied separately:
- A legitimate Goobies Windows x64 installation and the normal Steam client/account.
- A separately prepared DX11 development copy, not your original installation.
- Bundled UE4SS v3.0.1 Beta #0, Git d935b5b and tested settings/proxy.
  Other versions have not been verified. MIT license/source notices included.
- The local original Steam SDK must match the exact hash below. It is proprietary,
  is NOT included, and must never be obtained from this ZIP or another user's copy.
No Python, compiler, workspace, fixed drive letter or developer tool is needed.
The guard was built with a static MSVC runtime; Windows supplies system imports.

Installation (game closed; keep backups until all tests and rollback pass):
1. Close the game and back up existing Mods/mod_menu before extracting. Extract
   directly into Shooter/Binaries/Win64, or stage first to inspect. Set T to your
   development
   copy root containing Shooter; W=T/Shooter/Binaries/Win64; M=W/Mods.
   Set S=T/Shooter/Plugins/SteamCorePro/SteamCorePro/Source/ThirdParty/
   SteamLibrary/redistributable_bin/win64 (one continuous path).
2. In PowerShell use Get-FileHash -Algorithm SHA256 -LiteralPath <file>.
   W/Shooter-Win64-Shipping.exe must be 2880b2d3396a3f14f50c84a930286e3bbc1ebc456219bcbd9f3a85fccbdec90d.
   S/steam_api64.dll must be a44e5537939ae4eebc69000589aa9b2437a667813a1657cc779198bae9b815a9 (298856 bytes).
   If either differs, STOP. Other builds/SDK versions are unsupported.
3. Choose a NEW backup folder outside M; copy S/steam_api64.dll, M/mods.txt,
   W/Configs if present, and all configuration files affected by your setup.
   Verify each backup against its original. Do not overwrite an old backup.
   Preserve saves/logs. Move conflicting legacy/native mods intact outside M
   with a before/after file hash inventory; loader flags alone are insufficient.
   Do not erase or disable your unrelated mods without understanding their setup.
4. Require M/mod_menu and S/steam_api64_original.dll to be absent; otherwise STOP
   and review the existing installation. ZIP Mods/mod_menu maps to M/mod_menu.
   The included enabled.txt activates the manager; no mods.txt edit is needed.
   Do not copy Defaults into live W/Configs.
5. Copy the verified original S/steam_api64.dll to S/steam_api64_original.dll.
   Verify its original hash, then replace ONLY S/steam_api64.dll with ZIP
   native/achievement_guard_candidate.dll. Its hash must be
   342c54a15ca3b2b268a5bd29cd5380a6a04f7679bb57ba79b292c5cb2893556c. Never copy native into Mods/dlls.
6. The examples/ directory is an optional author template, not a required mod.
   Leave it outside M unless deliberately trying examples/ExampleMod.
   No acceptance fixtures, personal configuration or Menu Options are included.

First launch and checks:
Launch only your development copy using its verified existing DX11 launch route;
no launcher/game files are supplied. Stay at the main menu. Require a new S/
mod_menu_guard_<pid>_<tick>.log containing exactly
MM_GUARD_READY UserStats012 Client020 SDK_GAME_HASH_OK.
Missing readiness, MOCK_BACKEND_ONLY, a crash or Steam initialization failure:
STOP; do not start gameplay. Preserve guard log, W/UE4SS.log and crash output.
Open Mods: left list/right details, locked ON manager, working Back/Disable All.
Disable All must never disable ModMenu. With no additional mods installed,
the list contains only the locked manager and no Menu Options controls.
Editable toggles show Turn on/Turn off tooltips. Managed settings are supplied
by separate mods; unmanaged UE4SS/native mods cannot be disabled here.
Restart-required changes show a notice. Restart.ps1 is included for the explicit
confirmed Restart action; it normally closes and relaunches the same build.
There is no automatic startup restart. After restarting, staged choices persist.
Check ordinary/smaller/wide layouts and restoration of the vanilla main menu.
Do not reset earned achievements or deliberately unlock new ones for testing.
Real identity/callbacks, achievement/progress suppression, provider/dependency
failures and vanilla gameplay need explicit runtime evidence. No relevant BLOCK
call means suppression remains untested. Send logs, screenshots, resolution,
expected/actual behavior and this ZIP hash to the developer; redact account IDs.

Troubleshooting and uninstall/rollback (game closed):
Verify original backup hash first. Restore backed-up original SDK to
S/steam_api64.dll. Preserve any changed settings/logs and installed files outside
activation before removing ONLY introduced M/mod_menu, optional example and
S/steam_api64_original.dll after checking their identity. Restore exact saved
mods.txt after preserving test changes. Move quarantined mods back only if their
destinations are absent. Preserve live Configs/saves/evidence; do not blindly
restore/delete them. Retain all verified backups. Never overwrite unrelated data.

Not a sandbox, universal Steam blocker or Cloud/leaderboard protection.
Package integrity/local installation do not prove runtime or another PC works.
